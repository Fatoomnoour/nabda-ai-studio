# Antigravity Model Selection — Current Official Docs (checked 2026-11-17)

Official documentation: https://antigravity.google/docs/models and https://antigravity.google/docs/features

- **Initial repository audit / multi-file reasoning:** `Orchestrator (Argon)` if visible in the account's selector. It plans with Gemini 4 Argon and implements with Gemini 4 Hydrogen; **no selectable thinking effort** when Orchestrator is chosen. Available to eligible paid Google AI Pro, subject to account entitlements/rollout.
- **Standalone architecture-critical reasoning:** `Gemini 4 Argon — High`, if visible and useful for separate audit, not a default for every UI polish iteration.
- **Code implementation:** `Gemini 4 Hydrogen — High`, or keep `Orchestrator (Argon)` for reviewed multi-file tasks.
- **Routine UI polish:** `Gemini 3.8 Flash — Medium` for minor controlled CSS adjustments; if not available choose current fastest coding model shown.
- **Permissions:** prefer Default / review changes and terminal commands. Do not use Turbo/always-proceed for sensitive Git, secrets, deletion or deploy. Keep project folder scoped and review diffs.

**Google AI Pro subscription and Gemini API billing are separate.** A coding-model entitlement does not automatically authorize an application's paid Gemini requests. Check https://ai.google.dev/gemini-api/docs/billing separately before implementing production AI calls.
